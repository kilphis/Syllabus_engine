# クマダイ時間割 × Obsidian

[クマダイ時間割](https://syllabus-engine.vercel.app) の画面右上「🟣 Obsidian(.md)」で書き出したノートを、
この保管庫にそのままドラッグ＆ドロップすれば、週間タイムテーブルと講義一覧が入ったノートとして開けます。

## 毎週の課題・復習タスク（Tasks プラグイン）

ノート内の「今週のタスク」に、講義ごとの毎週繰り返しタスク（`🔁 every week`）が入っています。

### 初めて Tasks を使う人向け（3分）

1. 設定 → コミュニティプラグイン → 閲覧 → 「**Tasks**」を検索してインストール → 有効化
2. 書き出したノートを開く。「やること一覧（締切順）」の ` ```tasks ` ブロックが、未完了タスクを締切順に並べた**ダッシュボード**として表示されます（自分でクエリを書く必要はありません）
3. タスクのチェックボックスをクリック → その回が「完了」になり、**日付を1週間進めた次のタスクが自動で追加**されます

ポイント：新しい週が来ても勝手には増えません。「**今週の分をチェックしたら来週の分が湧く**」仕組みです。だから「講義に出た → 帰宅して Obsidian を開き、今日の分にチェック」という流れで自然に回ります。休講でオンデマンド課題が出た週などは、その週のタスクだけ書き換えたり増やしたりして使ってください。

> タスクの起点は「今日以降で最初のそのコマ」になっています。学期の途中で書き出しても、いきなり過去や遠い未来の日付にはならず、今週から並びます。

### 締切（📅）の付け方

クマダイ時間割の「🗓️ 課題の締切」ボタンで、講義ごとに締切タイミングを選べます（設定はブラウザに保存されます）。

- **日付が変わる前** … その授業日のうちが締切（`⏳` と `📅` が同じ日）
- **次の講義開始前** … 翌週の同じコマの前日が締切
- **課題はあるけど不定期** … タスクは出すが締切（`📅`）は付けない
- **課題がない** … その講義のタスク自体を出さない

選んでから .md を書き出すと、タスクに `📅 締切日` が付きます。

## カレンダー表示も使いたい場合（Full Calendar プラグイン）

1. コミュニティプラグイン「Full Calendar」をインストール・有効化
2. 「📅 カレンダー(.ics)」で書き出した `.ics` ファイルもこの保管庫に置く
3. Full Calendar の設定でその `.ics` ファイルをカレンダーソースとして追加

これで週間ビューに講義が時間割どおり表示されます。`.ics` は Google カレンダーなど他サービスへのインポートにも使えます。
